# 360-spherical-viewer
360 PANORAMA VIEWER is an offline-ready web app to view 2:1 equirectangular 360 spherical photos and 360 videos. Features include smooth auto/manual rotation, zoom, auto-fading degree HUD, dual-camera 180° opposite-angle VR side-by-side mode, bulk local uploads saved via IndexedDB, video playback controls, and stock panoramas powered by MABJAS
